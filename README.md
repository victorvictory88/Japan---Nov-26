# Tokyo and Osaka, Nov 21 to 29, 2026

Family trip app built from our planner sheet. Open it on a phone, then use Share > Add to Home Screen.

index.html holds the whole app (data, styles, script). The img folder holds the day maps (Google Maps captures) and the place photos (Google Street View captures and Wikimedia Commons photos, credited on each card).

To change the plan, edit the DAYS list near the top of the script in index.html.
